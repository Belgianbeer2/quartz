## Flashcard — Deck 1 · Concept → Définition

### L0

| Concept | Définition |
|---|---|
| Fenêtre d'activation | Zone de tolérance physiologique optimale. En dehors : PFC moins disponible, recadrage dégradé. |
| Intéroception | Perception des signaux corporels internes — premier point de détection des émotions avant le nommage. |
| Co-régulation sociale | Restauration L0 via présence d'une autre personne. Isolement prolongé dégrade le budget. |

### L1

| Concept | Définition |
|---|---|
| Besoin de Compétence | Besoin d'efficacité et de maîtrise. Défensif (Intransigeance) : l'erreur devient menace identitaire. |
| Besoin d'Autonomie | Besoin de contrôle sur ses décisions. Déclenche la Réactance si liberté menacée. |
| Besoin d'Appartenance | Besoin de place dans un groupe. Déclenche le Délaissement si bids for connection refusés. |
| Besoin de Contrôle | Besoin de levier sur les résultats. Déclenche l'Impuissance si levier absent. |
| Prémisses éthiques | Standards moraux préchargés. Déclenchent la Colère IRL via BIS si valeur violée. |

### L2

| Concept | Définition |
|---|---|
| Dissociation | Projection dans la tête d'un observateur — décisions depuis une image imaginée. |
| Confabulation | Justification a posteriori d'une décision émotionnelle. 3 marqueurs : sélectivité, causalité inversée, certitude rapide. |
| Sélectivité mémorielle | Reconstruction biaisée selon l'état présent — sous Peur : ne retient que les pertes. |
| Vision zoomée | Fenêtre temporelle trop courte — 3 sessions = "tendance". Produit la Peur des résultats. |
| Pensée binaire | Évaluation tout-ou-rien — produit le verdict identitaire dans la Honte. |
| Piédestal | Surévaluation de l'enjeu — transforme la Plénitude en pression. |
| Suranticipation | Projection des conséquences en cascade avant qu'elles existent. Amplifie l'Impuissance. |
| Scattering | Dispersion attentionnelle défensive — trop de fronts actifs pour éviter l'engagement réel. |
| Auto-flagellation | Jugement sévère post-erreur → renforce la Honte en boucle. Opposé : Self-compassion. |
| Rumination | Répétition mentale sans résolution — tourne en boucle sans nouvelle information produite. |
| Suramplification | Engagement maximal compensatoire — épuise L0 rapidement. |

### L3

| Concept | Définition (mécanisme + BIS/BAS + action tendency) |
|---|---|
| Agacement standalone | BIS léger sur irritant externe, BAS neutre. Signal comportemental : gestes secs. Retirer l'irritant. |
| Agacement signal L0 | Même déclencheur mais réaction disproportionnée = budget L0 épuisé. Le "quart de tour" est un proxy L0. |
| Frustration | BAS actif bloqué, BIS neutre. "Bol qui se remplit" — signal précoce avant Colère. |
| Colère | BAS frustré + BIS réactif. Transformable en Détermination via redirection du contrôle perçu. |
| Colère IRL | BAS↑↑ frustré (obstacle) ou BIS↑ éthique (valeur violée). Transformable — distinct de la Colère in-game. |
| Réactance | BAS très actif + obstacle sur liberté d'action. Confabulation comme véhicule — 3 marqueurs. |
| Peur | BIS très élevé, BAS bas. Double circuit LeDoux. Objet financier/identitaire — distinct de la Honte. |
| Honte | BIS très élevé, BAS bas. "Je SUIS défaillant." Carburant : entity thinking. Distinct de la Culpabilité. |
| Culpabilité | BIS actif, BAS vers réparation. "J'AI fait" — résolvable contrairement à la Honte. |
| Impuissance | BAS bas (absence de levier), BIS neutre. Souvent sous-jacente à Réactance et Colère. |
| Accablement | BAS très bas, BIS très bas. Phase post-épuisement — recadrage inaccessible. Signal de sortie : Sérénité. |
| Délaissement | BIS actif (connexion refusée), BAS bas. Déclencheur type : "vu" sans réponse. |
| Anxiété d'évaluation | BIS actif, BAS neutre. Véhicule : Dissociation. Objet : regard d'un pair compétent. |
| Tristesse | BAS↓ BIS neutre. Réponse à une perte identifiable. Se traverse — ne se réprime pas. Distinct de l'Accablement. |
| Solitude | BAS↓ BIS neutre-bas. Absence structurelle de lien. Distinct du Délaissement (connexion refusée). |
| Doute | BIS↑ léger. Fonctionnel (garde-fou) vs paralysant. L'absence de doute = signal de confabulation. |
| Déception | BAS↓ BIS neutre. Écart attente/résultat. Distinct de la Frustration (BAS bloqué) et de la Peur (menace). |
| Certitude | BAS↑ BIS↓. Stratège actif. Risque : fausse certitude entity thinking — vérifier l'ancrage analytique. |
| Détermination | BAS↑↑ BIS neutre. Précurseur de Suramplification si l'engagement devient défensif. |
| Curiosité | BAS↑ BIS↓. Mode Starbursting — NFC-aligné. Protéger le contexte pour maintenir ce mode. |
| Enthousiasme | BAS↑↑ BIS↓. Précurseur de Piédestal si surestimation de l'enjeu s'active. |
| Satisfaction | BAS neutre BIS↓. Fermeture de boucle — restauratrice. Distinct de la Plénitude. |
| Plénitude | BAS actif, BIS bas. À documenter en comportements — base des reconvocations Stratège. |
| Plénitude IRL | BAS↑ BIS↓. Co-régulation sociale. Restaure L0. Nourrit la Plénitude in-game via le renforcement identitaire. |
| Sérénité | BAS léger, BIS bas. Signal de sortie de l'Accablement — le recadrage redevient accessible. |
