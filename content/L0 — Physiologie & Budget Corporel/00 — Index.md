# 🫀 L0 — Physiologie & Budget Corporel

> L0 est le niveau zéro du modèle. Il précède L1. Il conditionne tout ce qui suit.
> Sans ce niveau, le modèle entre par la cognition — alors que le corps parle avant.

---

## Pourquoi un niveau zéro ?

> [!abstract] ✅ Fondement solide — Barrett (2017, 2020)
> Le cerveau gère en permanence les ressources du corps (énergie, glucose, eau, température). Cette gestion — l'allostase — produit l'affect brut (valence + activation) qui est le *matériau de base* de toutes les émotions. L1 préconditionne les prédictions. Mais L0 détermine les ressources disponibles pour faire fonctionner L1, L2, L3.[^1]
>
> Un L1 bien-être peut être actif et pourtant produire des prédictions défensives si L0 est épuisé.

**L0 n'est pas émotionnel — il est physiologique. C'est pourquoi il est distinct.**

## Relation avec les autres niveaux

```
L0 (physiologie) → détermine les ressources disponibles
    ↓
L1 (prédictions entraînées) → préconditionne le traitement
    ↓
L2 (opérations cognitives) → traite l'information
    ↓
L3 (émotions construites) → signal + action tendency
    ↓
L4 (comportements) → plan d'action
    ↓ (boucle de rétroaction)
L0 (comportement régule le budget corporel)
```
