# 🫀 L0 — Intéroception

> *"La capacité à percevoir les signaux internes du corps est le fondement de la conscience émotionnelle."* [documenté — Seth 2013]

---

## I. Définition

> [!abstract] ✅ Fondement solide — Seth (2013) · Garfinkel (2015)
> L'**intéroception** est la perception des signaux internes du corps — rythme cardiaque, respiration, tension musculaire, température interne, sensations viscérales. Le cerveau lit ces signaux en continu pour maintenir l'allostase.
>
> L'affect brut (valence + activation) de Barrett est directement construit depuis ces signaux intéroceptifs. Ce n'est pas une métaphore : la conscience émotionnelle commence dans le corps, pas dans la pensée.[^1]

**L'acuité intéroceptive** (capacité à lire précisément ces signaux) prédit la granularité émotionnelle — les personnes qui lisent mieux leur corps ont de meilleurs outils de régulation.[^2]

---

## II. Ce qui manquait dans le modèle

Le protocole In-Game actuel entre par le nommage de l'émotion (L3). Mais l'émotion est déjà construite quand on la nomme — le signal corporel est arrivé avant.

**Ce qui devrait précéder :** un scan intéroceptif rapide qui identifie l'affect *avant* de le catégoriser.

```
Signal corporel (intéroception)
    ↓
Affect brut : valence (agréable/désagréable) + activation (haute/basse)
    ↓
Concept appliqué → Émotion nommée (L3)
```

Entrer par le corps donne un accès plus précoce — avant que L2 ait eu le temps de construire une narration.

---

## III. Application pratique — scan intéroceptif

**Trois questions en 10 secondes :**

1. *"Est-ce que quelque chose dans mon corps est tendu/contracté ?"* → localiser
2. *"Est-ce que mon rythme cardiaque est élevé, normal, bas ?"* → activation
3. *"Est-ce que la sensation est agréable, désagréable, neutre ?"* → valence

Ces trois données donnent l'affect brut. L3 se nomme ensuite depuis là — pas depuis la pensée.

## IV. Variables documentées

| Signal | Corrélat probable dans le modèle |
|---|---|
| Tension cervicale / épaules | Activation haute · souvent Piédestal ou Dissociation actif |
| Respiration courte / haute | BIS élevé · Anxiété d'évaluation |
| Tension abdominale | Peur · anticipation d'un résultat négatif |
| Légèreté / fluidité | BAS élevé sans BIS · Plénitude ou Certitude |
| Lourdeur / pesanteur | Budget épuisé · Impuissance |
