# ⚙️ Opérations L2 — Table des mécanismes cognitifs

> Les opérations L2 sont **neutres**. Ce sont des mécanismes universels du traitement cognitif. Ce qui est documenté dans les fiches (Dissociation, Confabulation...) en sont les pôles mal-être. Les pôles bien-être émergent de l'expérience — ils ne se théorisent pas à l'avance.

## Ce que la neutralité signifie

Chaque opération est un **mécanisme universel** — présent chez tout le monde, dans les deux boucles. L'appui L1 détermine quel pôle s'active :

| Appui L1 Peur | Opération neutre | Appui L1 Confiance |
|---|---|---|
| Dissociation | Mentalisation | Empathie |
| Confabulation | Évaluation causale | Analyse fondée |
| Vision zoomée | Calibration temporelle | Perspective long terme |

> [!warning] Gap documenté — pôles bien-être
> Les opérations 06 à 09 n'ont pas encore de pôle bien-être nommé. À documenter par l'expérience, pas à théoriser à l'avance.

---

## Principe de discrimination L2 / L3

Un L2 **opère** — il traite. Un L3 **ressent** — il est vécu.

La Dissociation (L2) produit une interprétation (*"le reg pense que je suis mauvais"*). L'Anxiété d'évaluation (L3) est l'état émotionnel que cette interprétation génère. On peut avoir le L2 actif sans encore identifier le L3 — la détection de L2 est souvent plus précoce.
