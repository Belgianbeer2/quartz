# 🌅 Protocole — Avant session

> Objectif : vérifier le budget · calibrer les attentes · poser l'intention depuis le Stratège.
> Durée : 10-15 minutes maximum.

---

## Étape 1 — Budget corporel (L0)

→ [[L0 — Physiologie & Budget Corporel/02 — Allostase]]

- Sommeil : ok / dégradé / mauvais
- Chaleur : ok / élevée / intense
- Co-régulation récente : ok / réduite / absente

**Si 2+ dégradés → adapter l'intention de session. Ne pas viser le 100%.**

---

## Étape 2 — Scan intéroceptif

→ [[L0 — Physiologie & Budget Corporel/01 — Intéroception]]

*"Est-ce que quelque chose est tendu ?"* → localiser
*"Mon activation est haute, normale, basse ?"*
*"La sensation est agréable, désagréable, neutre ?"*

→ Si tension localisée : nommer l'affect brut avant de nommer l'émotion.

---

## Étape 3 — BIS/BAS — quel état motivationnel ?

→ [[🧭 Boussole émotionnelle]] Section 2

- BAS élevé + BIS bas → énergie libre → intention : jouer depuis l'identité
- BAS élevé + BIS élevé → Piédestal potentiel → intention : *"je joue depuis moi, pas pour l'image de cette forme"*
- BAS bas + BIS élevé → retrait potentiel → intention : session courte · validation processus

---

## Étape 4 — L1 actuel

→ [[L1 — Structures profondes/01 — Besoin de Compétence]]

*"Quel est mon appui en ce moment — Peur ou Confiance ?"*
Si Peur → identifier le L1 défensif actif → nommer → ne pas nier.

---

## Étape 5 — Intention depuis le Stratège

Une seule phrase. Depuis l'identité, pas depuis le résultat.

✗ *"Aujourd'hui je veux gagner X"*
✓ *"Aujourd'hui je joue en Stratège de la performance durable — je lis, je décide, je m'adapte"*
