# ⚙️ Projection temporelle -- Suranticipation

> *"Le cerveau projette toujours le présent dans le futur. Sous entity thinking, cette projection devient soit catastrophiste soit euphorique — jamais calibrée."*

---

## I. L'opération neutre — Projection temporelle

**Définition fonctionnelle :** Mécanisme par lequel le cerveau extrapole un état présent vers le futur pour anticiper ce qui va arriver. Mécanisme adaptatif — sans lui, pas de planification ni de gestion de la variance.

> [!abstract] ✅ Fondement — Barrett (2017) · Kahneman (2011)
> Le cerveau est une machine prédictive — il projette le présent dans le futur en permanence (Barrett 2017). Le biais de récence amplifie cette projection : les données récentes sont pondérées plus lourdement dans la prédiction que les données historiques (Kahneman 2011). Sous budget L0 épuisé, ce biais s'accentue encore. [documenté]

**Modulation par L0 :** sous budget épuisé, le biais de récence est amplifié — l'état présent (bon run ou mauvais run) prend une place disproportionnée dans la projection. La projection calibrée devient inaccessible.

**Universalité :** anticiper est nécessaire. La dysfonction naît de la qualité de la projection — trop sombre ou trop lumineuse — pas de la projection en elle-même.

---

## II. Cartographie des pôles

> **Note méthodologique :** la Suranticipation a deux expressions opposées selon la direction de l'état projeté (défavorable vs favorable) et le rôle de l'entity thinking dans chacune.

#### A. Pôle défensif — Suranticipation

**Expression 1 — Anxieuse : bon run → anticipation de la chute**
- **Condition :** bon run + entity thinking + L1 Compétence défensif (Perfectionnisme protecteur)
- **Mécanisme :** bon run est traité comme révélation de l'entité fixe → entité fixe = fragile, pas durable → anticipation anxieuse du retournement inévitable → budget dépensé en anticipation d'une menace non encore réelle
- **Lien entity thinking :** l'entity thinker ne peut pas traiter le bon run comme variance favorable. C'est une donnée sur son entité, et l'entité fixe est toujours susceptible d'être "démasquée". Le bon run crée autant d'anxiété que le mauvais.
- **Output typique :** jeu contracté · réduction du volume · "je gagne trop pour le moment" → BIS activé en prévention
- **L3 générée :** [[Peur]] latente · [[Anxiété d'évaluation]]
- **Statut :** [documenté — Alexis 03-02-2026]

**Expression 2 — Euphorique : bon run → traiter le run good comme état normal**
- **Condition :** bon run + entity thinking + L0 satisfait + BAS élevé
- **Mécanisme :** bon run est attribué à la compétence fixe révélée plutôt qu'à la variance favorable → projection que cet état est la norme → sous-estimation du retournement inévitable → surconfiance non calibrée
- **Lien entity thinking :** symétrique de l'expression 1. L'entity thinker traite les bons résultats comme preuve de l'entité — donc les projette comme état stable. La variance n'est pas intégrée dans la projection.
- **Output typique :** montée des tables non justifiée · augmentation du volume sans calibration · activation du Piédestal · surprise douloureuse au premier retournement
- **L3 générée :** excitation irrationnelle → puis Honte et Frustration au retournement
- **Statut :** [adjacent — non encore documenté · inféré depuis entity theory + Kahneman biais de récence]

**Expression 3 — Catastrophiste : mauvais run → anticipation d'un effondrement prolongé**
- **Condition :** mauvais run + entity thinking + L0 épuisé
- **Mécanisme :** mauvais résultats récents → biais de récence amplifié → projection que la tendance va se poursuivre indéfiniment → Vision zoomée co-active → "le système est cassé"
- **Lien entity thinking :** le mauvais run est traité comme révélation de l'entité déficiente — donc stable dans le futur
- **Output typique :** retrait · questionnement du niveau · activation cascade Retrait
- **L3 générée :** [[Peur]] · [[Impuissance]]
- **Statut :** [inféré depuis Kahneman 2011 · co-active avec Vision zoomée]

#### B. Pôle générateur — Projection ancrée

**Expression 1 — Variance reconnue dans les deux sens**
- **Condition :** mastery thinking + données long terme accessibles
- **Mécanisme :** bon ou mauvais run → variance reconnue comme symétrique. "Cet état est temporaire dans les deux sens." La projection reste dans la fenêtre correcte (4-6 mois).
- **Lien mastery thinking :** la compétence est incrémentale → les résultats à court terme sont du bruit statistique, pas des révélations
- **Output typique :** engagement stable · ni surconfiance ni contraction · maintien du processus
- **Statut :** [inféré depuis Dweck 2006 · à documenter par l'expérience]

## IV. Connexions dans l'écosystème L0→L4

| Niveau | Connexion |
|---|---|
| **L0** | Budget épuisé amplifie biais de récence → Expression 3 plus probable. Budget satisfait + BAS élevé → Expression 2 plus probable |
| **L1 déclencheurs** | Besoin de Compétence défensif (Expr. 1 et 3) · Perfectionnisme protecteur |
| **L2 associés** | Vision zoomée (co-active Expr. 3) · Piédestal (précède ou suit Expr. 1-2) · Pensée binaire (amplifie la projection) |
| **L3 produites** | Peur · Anxiété d'évaluation · Frustration (post-retournement Expr. 2) |
| **L4 comportements** | Réduction volume (Expr. 1) · Montée de limites non calibrée (Expr. 2) · Retrait (Expr. 3) |

**Distinction des schémas proches :**
- vs **Vision zoomée** : la Vision zoomée évalue le passé sur une fenêtre trop courte. La Suranticipation projette le présent vers un futur non encore arrivé.
- vs **Piédestal** : le Piédestal gonfle l'enjeu du moment présent. La Suranticipation projette vers le futur.

## V. Régulation — Stratégies Gross

| Stratégie | Applicable | Application |
|---|---|---|
| 1 · Sélection | non | La situation de bon/mauvais run ne se sélectionne pas |
| 2 · Modification | non | — |
| 3 · Attentionnel | oui | Revenir à la décision présente — *"je joue ce coup, pas le run que j'imagine"* |
| 4 · Reappraisal | oui | *"La variance est symétrique — elle peut continuer dans les deux sens"* · Données long terme comme ancre |
| 5 · Modulation | partiel | Nommer la projection avant qu'elle s'installe |

**Stratégie prioritaire :** Déploiement attentionnel (3) in-game — ramener au coup présent. Reappraisal (4) hors session — données long terme comme correction du biais de récence.
**Si L0 épuisé :** ne pas consulter les résultats sous état épuisé (amplifie le biais de récence).

## VI. Signaux de détection

> [!warning] Le pattern Suranticipation est actif quand...
> - Un état positif présent génère une pensée sur son inévitable fin (Expression 1)
> - Un bon run produit de la surconfiance et des ajustements de volume non calibrés (Expression 2)
> - Un mauvais run est projeté comme tendance durable plutôt que comme variance (Expression 3)
> - Les mots "de toute façon", "ça va casser", "je mérite pas ce run" apparaissent
>
> **Question de détection :** *"Est-ce que je suis dans cette session — ou dans la prochaine ?"*

---

## VII. Protocoles d'interruption

> [!tip] In-game
> *"Je joue ce coup — pas le run que j'imagine être en train de perdre ou de gagner."*
> Revenir à la décision devant soi. La variance est symétrique.

> [!tip] Hors session — si Expression 2 (euphorique)
> Avant toute décision de monter les limites : vérifier les données sur la bonne fenêtre (4-6 mois). Le bon run actuel est du bruit statistique favorable.

> [!tip] Post-session — si Expression 1 ou 3
> Nommer : *"Je suis en suranticipation."* La variance est symétrique dans les deux sens. Consulter les données long terme.

> [!tip] Si L0 épuisé
> Ne pas analyser les résultats récents sous état épuisé — le biais de récence sera maximal.
