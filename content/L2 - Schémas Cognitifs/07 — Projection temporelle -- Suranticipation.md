# ⚙️ Projection temporelle -- Suranticipation

> *"Le cerveau projette toujours le présent dans le futur. Sous entity thinking, cette projection devient soit catastrophiste soit euphorique — jamais calibrée."*

---

## I. L'opération neutre — Projection temporelle

**Définition fonctionnelle :** Mécanisme par lequel le cerveau extrapole un état présent vers le futur pour anticiper ce qui va arriver. Mécanisme adaptatif — sans lui, pas de planification ni de gestion de la variance.

> [!abstract] ✅ Fondement — Barrett (2017) · [[Fondements théoriques/03 — Cerveau prédictif]]
> Le cerveau est une machine prédictive — il projette le présent dans le futur en permanence. [documenté]

> [!abstract] ✅ Fondement — Kahneman (2011) · [[01 — Angles morts & évolutions]]
> Le biais de récence amplifie cette projection : les données récentes sont pondérées plus lourdement dans la prédiction que les données historiques. Sous budget L0 épuisé, ce biais s'accentue encore. [documenté]

**Modulation par L0 :** budget épuisé → biais de récence amplifié → l'état présent (bon run ou mauvais run) prend une place disproportionnée dans la projection. La projection calibrée devient inaccessible.

**Universalité :** anticiper est nécessaire. La dysfonction naît de la qualité de la projection — trop sombre ou trop lumineuse — pas de la projection en elle-même.

---

## II. Cartographie des pôles

> **Note méthodologique :** la Suranticipation a deux expressions opposées selon la direction de l'état projeté. Les deux découlent du même mécanisme entity thinking — mais dans des directions opposées.

#### A. Pôle défensif — Suranticipation

> **Rappel architectural :** la Suranticipation sert le L1 défensif en projetant les données présentes comme révélatrices de l'entité fixe — ce qui rend la projection anxieuse (le bon run peut être "perdu") ou irrationnellement positive (le bon run est "permanent").

**Expression 1 — Anxieuse : bon run → anticipation de la chute**
- **L1 actif :** Besoin de Compétence en mode défensif · Perfectionnisme protecteur
  *Ce qui est menacé :* l'entité compétente révélée par le bon run est fragile — le retournement l'invaliderait
- **Mécanisme L1→L2 :** bon run → "aujourd'hui je gagne trop" → la Compétence défensive traite le bon run comme révélation temporaire de l'entité (qui sera "démasquée" quand la variance tourne) → anticipation anxieuse du retournement → budget dépensé sur une menace non encore réelle
- **Condition déclenchante :** bon run prolongé + entity thinking + L1 Compétence défensif
- **Lien entity thinking :** l'entity thinker ne peut pas traiter le bon run comme variance favorable. C'est une donnée sur l'entité — et l'entité fixe peut toujours être "démasquée". → [[Fondements théoriques/09 — Mastery orientation · Entity theory]]
- **Output typique :** jeu contracté · réduction du volume · BIS activé en prévention
- **L3 générée :** [[Peur]] latente · [[Anxiété d'évaluation]]
- **Statut :** [documenté — Alexis 03-02-2026 · "je gagne trop pour le moment"]

**Expression 2 — Euphorique : bon run → état normal fantasmé**
- **L1 actif :** Besoin de Compétence en mode défensif positif
  *Ce qui est menacé (inversé) :* l'image positive de l'entité "révélée" par le bon run — la minimiser serait nier l'entité
- **Mécanisme L1→L2 :** bon run → l'entity thinking attribue les bons résultats à la compétence fixe révélée plutôt qu'à la variance favorable → projection que cet état est la norme → sous-estimation du retournement inévitable → surconfiance non calibrée
- **Condition déclenchante :** bon run + entity thinking + BAS élevé + L0 satisfait
- **Lien entity thinking :** symétrique de l'Expression 1. L'entity thinker traite les bons résultats comme preuve de l'entité — donc les projette comme état stable.
- **Output typique :** montée des limites non calibrée · augmentation du volume · Piédestal · surprise douloureuse au retournement
- **L3 générée :** excitation irrationnelle → puis [[Honte]] et [[Frustration]] au retournement
- **Statut :** [adjacent — inféré depuis entity theory + Kahneman · [[01 — Angles morts & évolutions]]]

**Expression 3 — Catastrophiste : mauvais run → effondrement prolongé anticipé**
- **L1 actif :** Besoin de Compétence défensif
  *Ce qui est menacé :* la validité du système entier — le mauvais run suggère que l'entité est définitivement déficiente
- **Mécanisme L1→L2 :** mauvais résultats récents → biais de récence amplifié → Vision zoomée co-active → projection que la tendance va se poursuivre indéfiniment → "le système est cassé" → "je ne suis pas ce joueur"
- **Condition déclenchante :** mauvais run + entity thinking + L0 épuisé
- **Lien entity thinking :** le mauvais run révèle l'entité déficiente — stable dans le futur
- **Output typique :** retrait · questionnement du niveau · activation cascade Retrait
- **L3 générée :** [[Peur]] · [[Impuissance]]
- **Statut :** [inféré depuis Kahneman 2011 · co-active avec Vision zoomée]

#### B. Pôle générateur — Projection ancrée

**Expression 1 — Variance reconnue dans les deux sens**
- **Condition :** mastery thinking + données long terme accessibles + L0 satisfait
- **Mécanisme :** bon ou mauvais run → variance reconnue comme symétrique. "Cet état est temporaire dans les deux sens." La projection reste dans la fenêtre correcte (4-6 mois).
- **Lien mastery thinking :** la compétence est incrémentale → les résultats à court terme sont du bruit statistique, pas des révélations. → [[Fondements théoriques/09 — Mastery orientation · Entity theory]]
- **Output typique :** engagement stable · ni surconfiance ni contraction · maintien du processus
- **L3 générée :** Certitude · Sérénité
- **Statut :** [inféré · à documenter par l'expérience]

## IV. Connexions dans l'écosystème — Bidirectionnel

| Niveau | Sens | Connexion |
|---|---|---|
| **Opération neutre → L0** | intrinsèque | Coût modéré — la projection temporelle sollicite la mémoire de travail et l'imaginaire |
| **L0 → L2** | descendant | Budget épuisé → biais de récence amplifié → Expressions 1 et 3 plus probables |
| **L2(défensif) → L0** | ascendant ⚠️ | Anticipation anxieuse prolongée → activation du stress chronique → dépense L0 via HPA axis |
| **L2(générateur) → L0** | ascendant ✅ | Projection ancrée réduit l'anxiété de la variance → préserve le budget |
| **L1 → L2** | descendant | Besoin de Compétence défensif → Expressions 1-3 · Compétence générateur → Projection ancrée |
| **L2(défensif) → L1** | ascendant ⚠️ | Répétition renforce "les états présents préfigurent les états futurs" → ancre la fragilité identitaire liée à la variance |
| **L2(générateur) → L1** | ascendant ✅ | Projection ancrée répétée consolide "la variance est symétrique et non identitaire" → renforce la Compétence générative |
| **L2 associés** | latéral | Vision zoomée (co-active Expr. 3) · Piédestal (précède ou suit Expr. 1-2) · Pensée binaire (amplifie la projection) |
| **L3 produites** | descendant | Peur · Anxiété d'évaluation · Frustration (défensif) · Certitude · Sérénité (générateur) |
| **L4 comportements** | descendant | Réduction volume (Expr. 1) · Montée de limites non calibrée (Expr. 2) · Retrait (Expr. 3) |

**Distinction des schémas proches :**
- vs **Vision zoomée** : la Vision zoomée évalue le passé sur une fenêtre trop courte. La Suranticipation projette le présent vers un futur non encore arrivé.
- vs **Piédestal** : le Piédestal gonfle l'enjeu du moment présent. La Suranticipation projette vers le futur.

| Stratégie | Moment d'intervention | Application concrète |
|---|---|---|
| 1 · Sélection | Avant la situation | — (la situation poker ne se sélectionne pas sur ce critère) |
| 2 · Modification | Pendant — amont | — |
| 3 · Attentionnel | Pendant — amont | *"Je joue ce coup — pas le run que j'imagine être en train de perdre ou de gagner"* |
| 4 · Reappraisal | Pendant — aval | *"La variance est symétrique — elle peut continuer dans les deux sens"* · données long terme comme ancre |
| 5 · Modulation | Pendant / après | Nommer la projection avant qu'elle s'installe |

**Stratégie prioritaire :** Déploiement attentionnel (3) in-game — ramener au coup présent. Reappraisal (4) hors session avec données long terme.
**Note L0 :** sous budget épuisé, ne pas consulter les résultats récents. Le biais de récence sera maximal.

## VI. Signaux de détection

> [!warning] Le pattern Suranticipation est actif quand...
> - Un état positif présent génère une pensée sur son inévitable fin (Expression 1)
> - Un bon run produit de la surconfiance et des ajustements de volume non calibrés (Expression 2)
> - Un mauvais run est projeté comme tendance durable plutôt que comme variance (Expression 3)
> - Les mots "de toute façon", "ça va casser", "je ne mérite pas ce run" apparaissent
>
> **Question de détection :** *"Est-ce que je suis dans cette session — ou dans la prochaine ?"*

## VII. Protocoles d'interruption

> [!tip] In-game · Timebank
> *"Je joue ce coup — pas le run que j'imagine."*
> La variance est symétrique dans les deux sens.

> [!tip] Avant session
> Si Expression 2 (euphorique) : avant toute décision de monter les limites, vérifier les données long terme (4-6 mois).

> [!tip] Post-session · Review
> Nommer : *"Je suis en suranticipation."* Consulter les données long terme pour corriger le biais de récence.

> [!tip] Si L0 épuisé
> Ne pas analyser les résultats récents sous état épuisé — le biais de récence sera maximal.

>     targetPattern = p["pôle_défensif"];

>     let nameParts = p.file.name.split(" -- ");

> 
> let sections = content.split(/\n##\s+/);
> let matches = [];
> 
> let dateRe = /^(\d{2}-\d{2}-\d{4})/;
> let escaped = targetPattern.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
> let tagRe = new RegExp("\\[pattern::[^\\]]*" + escaped + "[^\\]]*\\]", "i");
> 
> for (let section of sections) {
>     let firstLine = section.split('\n')[0].trim();
>     let dateMatch = firstLine.match(dateRe);
>     if (dateMatch && tagRe.test(section)) {
>         matches.push(dateMatch[1]);
>     }
> }
> 
> if (matches.length === 0) {
>     dv.paragraph("*Aucun O&R lié — tagger avec `[pattern:: " + targetPattern + "]` dans l'O&R.*");
>     return;
> }
> 
> matches.sort().reverse();
> let rows = matches.map(date => {
>     let allMR = dv.pages('"Journal/Morning routine logs/2026"').where(p => p.file.name === date + " Morning routine"); let mrPage = allMR.length > 0 ? allMR[0] : null;

> });
