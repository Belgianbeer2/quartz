# 📋 L4 — Catalogue des comportements

> Inventaire des comportements observables documentés. Chaque L4 est lié à l'émotion L3 qui le génère et à la prédiction L1 qu'il renforce.

---

## Format

`L4 [comportement]` ← généré par `L3 [émotion]` ← déclenché par `L2 [mécanisme]` ← appui `L1 [prédiction]`
Effet sur budget corporel : dépôt (+) ou prélèvement (-)
Boucle L1 : renforce ou affaiblit quelle prédiction

---

## Catalogue

### Comportements de retrait / évitement

**Stratégie de l'autruche**
← [[Impuissance]] · [[Délaissement]]
← L2 Mentalisation -- Dissociation (dans le contexte pairs)
← L1 Besoin d'Appartenance (entravé)
Budget : prélèvement progressif (isolement amplifié)
Boucle L1 : renforce la prédiction *"l'appartenance est douloureuse → retrait protecteur"*

**Off-day non choisi**
← [[Peur]] (bad run)
← L2 Vision zoomée · Sélectivité mémorielle
← L1 Résultats-dépendance
Budget : neutre à court terme, prélèvement à moyen terme (perd la dynamique)
Boucle L1 : renforce *"quand je perds je dois m'arrêter"*

---

### Comportements compulsifs

**Étude acharnée post-erreur**
← [[Colère_IRL]] · [[La Honte]]
← L2 Pensée binaire · Évaluation causale -- Confabulation
← L1 Intransigeance envers soi · Perfectionnisme protecteur
Budget : prélèvement (fatigue cognitive)
Boucle L1 : peut renforcer *ou* affaiblir selon la qualité de l'étude — à distinguer

**Rejouer mentalement un spot**
← [[La Honte]] · [[Frustration]]
← L2 Traitement mémoriel -- Rumination
← L1 Punition envers soi
Budget : prélèvement (rumination = dépense sans résolution)
Boucle L1 : renforce *"l'erreur mérite punition"*

---

### Comportements génératifs

**Feedback structuré post-session**
← Boucle de bien-être · L1 Méta-accomplissement
Budget : dépôt (clarté cognitive, intégration)
Boucle L1 : renforce *"l'erreur est de l'information"*

**Connexion empathique (Plénitude IRL)**
← [[Plénitude-IRL]]
← L1 Appartenance satisfait
Budget : dépôt direct (co-régulation)
Boucle L1 : renforce *"la connexion réelle est possible et accessible"*

**Fold facile depuis le Stratège**
← Certitude · Détermination
← L1 Méta-accomplissement · Créativité comme identité
Budget : neutre à positif
Boucle L1 : renforce *"je joue depuis moi"*
